# WING CONTROLLER Desktop v1.2.20

Build: 20260921.7 (macOS Apple Silicon)
Date: 2026-09-21

## Fields are editable in the app again (WebKit inheritance bug)

Chrome let you type in every field, but the shipping app did not: WebKit inherits
`user-select: none` into form controls, so any input inside a card that set that
rule (the operations cards and their headers) refused the caret and behaved like
a read-only label while still looking editable. Chrome ignores the rule for form
controls, which is why it looked fine in a browser and not in the app.

Selection is now restored explicitly for every control that can be typed in
(`input`, `textarea`, `select`, `option`, `contenteditable`) and kept off only for
the controls that are dragged instead of selected (ranges, checkboxes, radios).

Two related usability fixes:

- Focusing a numeric or id field selects its content, so typing replaces the value
  instead of landing inside it (`-18` became `-12-18` if you clicked mid-number).
- **Right-click any editable field** for `Edit`, `Select All`, `Copy Value`,
  `Paste` and `Clear`; channel id fields keep their richer menu (matrix selector,
  paste, clear).

## Builder and library polish

- Removed the id chips (`1`, `1-2`, `1-8`, `9-16`, `17-24`, `25-32`) from the
  trigger and target panels: they added nothing and sat under the wrong field.
- Removed Quick Templates (both the header selector and the preset block) and the
  code behind them.
- **"Save changes"** in the Build Macro header: saves the draft to the library,
  same as "Save Draft", respecting Live Safe Mode and the unsaved-changes guard.
- Only the **logo** opens About; the title next to it is a plain label again.
- The inspector and the hover box now describe the per-macro row buttons
  (open, rename, courtesy notice, enable/disable) instead of borrowing the text of
  the container they live in.

## Model-dependent parameters: LMT

The compressor model that the matrices run on the test console (`LMT`) had no
parameters of its own in the catalogue, only the generic compressor ones that LMT
does not expose (`/dyn/thr` is silent on it). Its real parameters are now
selectable, with the appendix ranges and confirmed by reading the console:
`/dyn/tspd`, `/dyn/trans`, `/dyn/tgain`, `/dyn/ton`, `/dyn/comp`, `/dyn/cgain`,
`/dyn/con`, plus the mix label corrected (it exists on WARM, LMT and CMB).

## Also in this release (since 1.2.18)

Everything from 1.2.19: Test Action (Shoot) runs the real dispatcher; a changed
action target can no longer be sent or saved as the old one; a new macro starts
unconfigured and an incomplete one cannot be enabled nor break the session; the
library stops losing work (unsaved-draft guards, confirmations for destructive
meter actions, legacy-alias purge fixed); Live Safe Mode is real; the Meter Bridge
releases its source, syncs its style with the dock and shows numeric levels in
every style; the interface audit fixes (header overflow, column divider, contrast,
Win95 details, dialogs owning the keyboard); and the DEQ2/WARM parameters.

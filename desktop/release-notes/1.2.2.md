# WING CONTROLLER Desktop v1.2.2

Build: 20260919.4 (macOS Apple Silicon)
Date: 2026-09-19

## Key Highlights

- **Latching Connect / Disconnect Controls (Anti-Dummy Buttons):**
  - Renamed top master buttons from `Live / Stop` to `► Connect` and `■ Disconnect`.
  - Implemented authentic Windows 95 latching toggle button states:
    - **Disconnected:** `■ Disconnected` is sunken/latched and disabled; `► Connect` is raised, enabled, and ready to establish the session.
    - **Connecting:** `► Connecting...` is sunken and disabled; `■ Disconnect` is enabled to allow cancellation.
    - **Connected (Live):** `► Connected` is sunken, active (glowing green), and disabled; `■ Disconnect` is raised and enabled to terminate the session.
  - Operators can no longer click buttons repeatedly as dummy inputs.

- **Clear, Persistent & Lockable Top Console IP:**
  - Standardized `#wing-ip-top` within an authentic Win95 sunken input pill with text cursor and click-anywhere focus.
  - Added bidirectional synchronization with `localStorage` (`wing_console_ip`), ensuring custom console IP configurations persist across reboots, refreshes, and macro edits.
  - Selecting macros from the library no longer overwrites the active console IP.
  - When connected live, the IP field automatically locks (`disabled = true`, `.is-locked`) with informative tooltips to prevent accidental show interruption.

- **Separated Macro Library & Clean Builder Workflow:**
  - Extracted `Saved Macros` out of `Build Macro` into its own dedicated panel (`#macro-library-panel`) on top of the left stack.
  - Restructured `Build Macro` (`#macro-builder-panel`) directly beneath `Saved Macros`.
  - Relocated `Templates` drawer to the top of the composer (beneath the active recipe summary) for quick macro starts.
  - Embedded `Meter trigger response` directly inside Block 1 (Trigger Signal), making Block 1 self-contained.
  - Positioned `▶ Test Action (Shoot)` (`#send-osc`) alongside `✓ Check (Preflight)` (`#preflight-macro`) in Block 4 (Value To Send) for instantaneous live console firing and offline validation.
  - Kept low-level OSC raw paths and hex diagnostics in a dedicated drawer at the bottom.

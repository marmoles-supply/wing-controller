## Saving and loading: now for real

The export button delivered the JSON as a browser download: in the packaged app **it opened no dialog, left
no file** and the log still said it had been exported. It was in the audit as an open limitation.

- **Export**: the **macOS Save panel** opens (suggested name and extension filter), you choose folder and
  name, and the file is really written there. Afterwards a notice appears with **where it went** and **what
  sections it carries**, and the log records the path. If you cancel, nothing is written and it stays as
  `station_backup_export_cancelled`: a cancelled export can no longer be confused with a saved one.
- **Import**: the system **Open** panel, and then the **section picker** with what the file carries ("N
  macros", "N preferences"). **Only what you tick** is applied; the rest of the station (network, settings,
  theme, shortcuts) is not touched.
- **Per show**: a **Show name** field names the file (`wing_<show>_<date>.wingstation.json`, without
  accents or odd characters) and it is remembered for the next export; **so is the folder of the last
  backup**, so a tour does not scatter the files. The typical flow —Macros and Meters ticked, Network and
  Settings unticked— is explained in the guide, chapter 6, section *One file per show*.
- **A real fault that came up while testing it**: on restoring, the flat copy of preferences overwrote the
  watchlist that the file carries in its own field, so the restore looked as if it had loaded nothing. Now
  the fields of each section are applied last and they win.

## The meters, one per row and legible

- **One meter per row** in the working window, as in the bridge: with several columns the card was left at
  ~150 px and, as soon as there was signal, the value ate the name down to "TRI…". Now the name takes the
  width of the row, the value has its fixed slot and does not shrink, and the full name is in the tooltip.
- **Legible light theme**: the name was in mint green on a grey card. Now the name is in navy blue, the
  value in crimson and the dB graduations in ink grey. Measured in Chrome against the grey card: name
  10.4:1, value 7.1:1, graduations 6.7:1. In dark, the channel tag goes from 3.7:1 to 7.9:1.

## What to try

1. **Backup per show**: Properties → Backup, type a show name, tick **Macros** and **Meters**, press
   **Export station backup**: the Save panel must open with `wing_<show>_<date>.wingstation.json`, and on
   saving it must tell you where it went. Repeat the export and check that it remembers the name and the
   folder. Cancel the panel: nothing must be written and the log must say
   `station_backup_export_cancelled`.
2. **Load a show**: **Restore station backup**, choose the file, leave only **Macros** ticked (or only
   **Meters**) and accept: only that must change, and the network and the settings must stay as they are.
3. **Meters**: look at the Live Meters card with signal coming in, in light and dark theme: one row per
   meter, the full name (even while the value is moving) and legible graduations.
4. **Guide**: Properties → Guide & Help → **Open the complete guide**; search `show`, `panic`, `scope`;
   check that no project file name or reference to internal documents appears.

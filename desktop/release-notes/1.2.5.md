# WING CONTROLLER Desktop v1.2.5

Build: 20260919.7 (macOS Apple Silicon)
Date: 2026-09-19

## Key Highlights

- **Complete Fix & Refactoring of Saved Macros Row Layout:**
  - **Single-Row Flex Architecture:** Resolved layout degradation in `#macro-library-list` where rows were inheriting an incompatible 2-column CSS Grid from `.step-row`, causing elements to wrap onto three awkward lines with 50%-wide buttons.
  - **Strict Pixel Alignment:** Each macro row (`.macro-row`) is now a sleek, compact 24px single horizontal flex line containing:
    1. Grab handle `⋮⋮` (`.macro-drag-handle`) with hover activation so dragging only initiates from the handle, eliminating accidental mis-drags.
    2. Native multi-select checkbox `[✓]` (`.macro-check`) with Shift+Click range support.
    3. Category color dot `●` (`.macro-tag-dot`) with click-to-cycle functionality.
    4. Macro details button (`.macro-select-button`) showing numeric index, bold title, and live execution telemetry/summary.
    5. Dedicated compact courtesy notice bell icon button (`.macro-notice-btn`) displaying `🔔` (sunken/gold when ON, dim/raised when OFF) without text clutter.
    6. Enable toggle button (`.macro-enable-button`) cleanly sized at 54px with green `ENABLED` or neutral `OFF`.
  - **Density-Compact Specificity Isolation:** Added explicit rule overrides to prevent `body.density-compact` generic button and input sizing from distorting compact list items.

- **Polished Search & Filter Toolbar:**
  - Integrated search input into an authentic sunken box (`.library-search-box`) with a magnifying glass icon `🔍` and dynamic clear button `[✕]`.
  - Structured `Select All` / `Deselect All` button directly alongside the search field on a single line.

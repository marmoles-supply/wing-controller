# WING CONTROLLER Desktop v1.2.3

Build: 20260919.5 (macOS Apple Silicon)
Date: 2026-09-19

## Key Highlights

- **Standardized Technical Drawer & Button Nomenclature:**
  - **Quick Templates:** Renamed the top quick-start template drawer from `Templates` to `Quick Templates` (`details#templates-details`), positioned right under the When/If/Then recipe summary for rapid macro assembly.
  - **Advanced Trigger Tuning:** Renamed the meter trigger response drawer within Block 1 (Trigger Signal) from `Meter trigger response` to `Advanced Trigger Tuning` (`details#meter-response-details`), grouping cooldown, rearm hysteresis, dwell time, and transient vs stable modes into a clean collapsible drawer.
  - **Raw OSC Diagnostics:** Renamed the bottom technical preview drawer from `OSC details` to `Raw OSC Diagnostics` (`details#osc-details-drawer`), keeping raw OSC addresses and packet diagnostics folded at the foot of the editor.
  - **Verify Syntax (Preflight):** Renamed the offline dry-run button in Block 4 from `✓ Check (Preflight)` to `✓ Verify Syntax (Preflight)` (`#preflight-macro`), explicitly differentiating it from the live action shooter `▶ Test Action (Shoot)` (`#send-osc`).

- **Architecture & Workflow Separation:**
  - **Dedicated Macro Library Panel:** `Saved Macros` (`#macro-library-panel`) is independently mounted at the top of the left stack with its full action bar (Save Draft, Enable Selected, New, Duplicate, Delete, Export, Import).
  - **Dedicated Build Macro Panel:** `Build Macro` (`#macro-builder-panel`) directly beneath, 100% focused on sequential steps 1 -> 2 -> 3 -> 4 -> 5.
  - **Clear Live Firing vs Offline Validation:** Block 4 highlights `▶ Test Action (Shoot)` for instantaneous live OSC transmission to the Behringer WING, alongside `✓ Verify Syntax (Preflight)` for safe in-memory AST and bounds verification in Rust.

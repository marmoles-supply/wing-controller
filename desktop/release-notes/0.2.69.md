# WING CONTROLLER Desktop v0.2.69

Build: 20261002.6 (macOS Apple Silicon)
Date: 2026-10-02

Same release as 0.2.68, with one correction in the helper that travels inside it: `set-custom-icon.sh`
used to refuse to patch an application that was running (exit 1), which is exactly the state an operator
is in when they run the unblock command — and the disk image shipped that refusal. It now patches the
bundle and says that the open window keeps the old icon until it is relaunched. Everything else is
0.2.68: the changelog and the release note inside the disk image and the ZIP, the helper under its
English name, and the custom icon written into every copy of the application.

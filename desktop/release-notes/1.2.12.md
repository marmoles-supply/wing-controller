# WING CONTROLLER Desktop v1.2.12

Build: 20260920.6 (macOS Apple Silicon)
Date: 2026-09-20

## Meters and macro editor

- Meter Bridge now keeps the latest watchlist subscription while its native stream starts, so an early UI update is not lost. Replaced streams cannot receive stale updates.
- Added click and drag-area meter selection, selected-count display, Remove button, and right-click removal. Watchlist changes resubscribe the native stream.
- Meter status distinguishes disconnected, connecting, and no-frame states; subscription errors are logged instead of hidden.
- Macro Matrix selects one primary trigger channel, clears numeric selections when changing source category, and shows only categories supported by the active field. Closing the Matrix always restores text selection.
- Macro names save on edit completion. Renamed the source family to Sources and aligned trigger channel labels/help.

## Validation and boundary

- TypeScript, HA, X32, desktop UI tests, and all 77 native Rust tests pass.
- Maillot Channel 3 read-only USB meter frames were received from a real WING Rack on Ethernet. This does not validate UI live connection/reconnect or macro actions on hardware; no OSC actions were sent during validation.
- Maillot 3.1.0 Channel 3 defines native meter subscribe/renew order and normal level scale of 1/256 dB; this release does not change request/decode order or meter scale.

# WING CONTROLLER Desktop v0.2.63

Build: 20261001.2 (macOS Apple Silicon)
Date: 2026-10-01

Three things, all of them about the application telling the truth.

## A toggle step no longer offers a value it does not send

The "VALUE TO SEND" section showed **ON (muted) / OFF (unmuted)** for a toggle step. They are the value a
step writes, and a toggle writes none: it sends `-1` and the console flips the parameter itself. The
toggle path hid them, and a renderer running afterwards showed them again — so two buttons sat there for a
value that never leaves the application, and since nothing in that step reads the parameter, they never
changed.

The hint under them described the pre-0.2.61 behaviour as well ("reads the current state and sends the
opposite"). It now says what actually happens: one packet carrying `-1`, nothing read first, no waiting
behind a fade's queue, reported as **sent** rather than confirmed, and not idempotent. The inspector's
description of the mode selector and both affected guide chapters said the same outdated thing and now
agree with the code.

## Installing keeps the application's icon

The installed copy had gone back to the dark system tile. The install needs `xattr -cr` (the bundle
arrives quarantined) and that deletes `com.apple.FinderInfo` — where a custom icon lives — so macOS 26
drew its own rounded tile behind the artwork. `desktop/build-dist.sh` re-applies the icon after the same
command; `scripts/verify-install.sh --install` did not. It does now, and the release verification fails if
the installed copy has lost it.

## What the recent changes left behind

- Two constructors in `wing-core` that nothing called (`parameter`, `state_parameter`), from an older
  generation of the catalogue, plus a doubled and self-contradicting doc comment on `dead_parameter`.
  `cargo build --workspace` is warning-free again.
- The template buttons were removed from the window earlier, but their apparatus was still in the file:
  six CSS rules for `.template-button`/`.template-grid`, a loop that queried buttons which do not exist,
  `applyTemplate`, `inferTemplate`, a dead helper and `selectedTemplate` — a variable written in eight
  places and read only by that loop.
- Every one of the 231 interactive elements in the window is referenced by script, and every health row is
  a live counter. `execute_toggle_step_by_reading` stays on purpose: it is the tested escape hatch for a
  console that does not implement the native flip.

# WING CONTROLLER Desktop v1.2.4

Build: 20260919.6 (macOS Apple Silicon)
Date: 2026-09-19

## Key Highlights

- **Accessory Drawer De-Beveling & Logical Relocation:**
  - **Quick Templates:** Relocated out of the primary step-by-step configuration flow. Added as a swift selector dropdown (`⚡ Quick Templates...`) directly in the `Build Macro` header (`#quick-template-select`) and as an un-beveled subordinate drawer right before the recipe summary (`details#templates-details`).
  - **Flat Accessory Styling:** Removed heavy 3D beveled borders (`border: 2px solid`, `box-shadow`, face-2 background) from all three accessory drawers: `Quick Templates` (`#templates-details`), `Raw OSC Diagnostics` (`#osc-details-drawer`), and `Advanced Trigger Tuning` (`#meter-response-details`). They now visually read as subtle, flat, subordinate tools with clean indented left guide lines and subtle disclosure chevrons.

- **Courtesy Trigger Notice Window (courtesy notice pop-up):**
  - **Per-Macro Option:** Added a dedicated toggle in Block 1 (`#macro-courtesy-notice`) and a quick-toggle bell icon (`🔔`) in each Saved Macro row to enable/disable courtesy trigger notices.
  - **Non-Intrusive Floating Toast:** Distinct from the high-priority modal/overlay HUD alert. Pops up in the bottom-right corner (`#courtesy-notice-container`) when the macro fires, displaying an authentic Win95 floating card with macro title, action breakdown, trigger timestamp, auto-dismiss progress bar (3.5s), and immediate dismiss `[✕]`.

- **Saved Macros Power-User Customizations & Batch Actions:**
  - **Drag & Drop Reordering:** Ergonomic HTML5 drag & drop on macro rows using drag handles `⋮⋮` with visual insertion indicator lines (`.drop-indicator-top`, `.drop-indicator-bottom`), immediately persisting the reordered library to disk.
  - **Multi-Selection & Batch Operations:** Row checkboxes (`[✓]`) with Shift+Click range selection and Cmd/Ctrl+Click toggle. Action toolbar dynamically adapts with batch counts: `Enable Selected (N)`, `Disable Selected (N)`, `🔔 Notice (N)`, `Duplicate (N)`, `Delete (N)`.
  - **Color Category Tags:** Cycleable color indicator dot per macro (`none`, `red`, `green`, `blue`, `amber`, `purple`) displayed in both the list row and the builder header for color-coded organization.
  - **Live Filter / Search:** Instant filter input (`#library-filter-input`) dynamically searching by macro name, trigger address, and action target.
  - **Accessible Move Controls:** Dedicated `▲` and `▼` toolbar buttons for quick single or multi-item movement without dragging.

- **Rust Runtime & DTO Parity:**
  - Added `courtesy_notice: bool` and `color_tag: Option<String>` to `ShowRunnerConfigDto` in `desktop/src-tauri/src/main.rs` with `#[serde(default)]` for complete backwards compatibility with existing saved macro libraries.

## First public Apple Silicon community beta

This is the first downloadable application accompanying the public source
repository. It targets Apple Silicon / arm64 Macs; the release environment is
macOS 26.6.2. Other macOS versions, Intel, Windows and Linux are not verified.
The certificate is stable and self-signed; this is not Apple Developer ID signing
and the app is not notarised by Apple. See the included installation instructions.

## Download and install

Under the release's **Assets**, download
`WING_CONTROLLER_v0.3.0_AppleSilicon.dmg` and `SHA256SUMS.txt`.
GitHub's **Source code** downloads are not installers.

1. Run `shasum -a 256 "WING_CONTROLLER_v0.3.0_AppleSilicon.dmg"` in the
   download folder and compare the complete hash with its checksum-file entry.
2. Open the DMG and drag **WING CONTROLLER.app** into **Applications**.
3. Eject the image and launch the installed copy. If macOS blocks it, check the
   origin/checksum and, if you choose to proceed, use **System Settings →
   Privacy & Security → Open Anyway** for this app. Do not disable Gatekeeper
   globally or override a malware-detected warning.
4. Grant microphone access only for LTC input. Read the operator guide and
   validate your setup away from a show before connecting to a console.

The ZIP contains the same application as an alternative archive. The optional
English recovery helper is restricted to this release's validated executable.
The `Legal` folder includes terms, dependency notices and source information.

## Explicitly open acceptance work

**The owner has not tested LTC.** Generated waveform fixtures do not establish
real interface/generator interoperability. Real LTC/MTC, device lifecycle,
native permission workflows, four-hour show endurance, controlled WING acceptance
and abrupt-exit/power-loss station recovery remain open. Individual atomic files
and a pre-restore snapshot do not establish a transaction across every store.
Use the published audit and roadmap to contribute reproducible evidence.

The source gate and package verification are separate checks. Their measured
results are recorded in the release validation report; neither certifies a live
show or guarantees another Mac's first downloaded-app experience.

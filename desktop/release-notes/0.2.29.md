# WING CONTROLLER Desktop v0.2.29

Build: 20260922.2 (macOS Apple Silicon)
Date: 2026-09-22

Fix release over 0.2.28: **the inspector no longer reads the dialogs' internal control
identifiers out loud**.

## The fault

The buttons and fields of the reusable dialogs (`win95-confirm`, `win95-prompt`,
`macro-delete-confirm`, `meters-confirm`, `meters-prompt`) carried no description of their own, so the
inspector fell back to its last resort — humanising the `id` — and showed things like **"Win95 confirm
accept"** or **"Win95 confirm cancel"** for the Accept and Cancel buttons.

## The fix

- **The twelve dialog controls now have an operator description**: *"Accept this question and
  carry the action out"*, *"Close this question without doing anything"*, *"Accept the name you have
  typed"*, *"Type the name here; Enter accepts and Escape cancels"*, *"Delete the selected macros from
  the library"*…
- **Two new safeguards so it cannot slip back in**:
  - A **static contract** (`scripts/test-desktop-window-dialog-contracts.mjs`) requires every
    `<button>`, `<input>` or `<select>` inside a dialog to carry `title`. It also covers the dialogs
    that the browser tests never open.
  - The inspector test **now fails** if a control without `title` is described with its own humanised
    `id`. Before, it was enough for there to be *something* longer than 20 characters, and the humanised
    identifier passed that filter: that is why it was not detected.

## What 0.2.28 already brought (included here)

- **Trigger latency metrics** in Diagnostics (p50/p95 and the worst case over the last 256
  samples, from the arrival of the datagram to the action emitted to the window) and the real scale of
  the meters (`1/256 dB → dBFS`).
- **Honest connection state**: `failed` ("Cannot reach console") separate from `offline` ("Connection
  lost") and `idle` ("Disconnected"), with the error visible under Connect + Listen.
- **Live Safe Mode visible**: `[LOCKED]` chip with the reason, guards on the paths that mutate the
  library, arming that also refuses in `connecting`/`reconnecting`, and in-memory rollback if a
  write fails.
- **Meter Bridge**: CLIP and peak in the VU and history styles (peak hold unified across the four
  views), *sticky* scale ruler, remove per strip, aligned column header, a bank's empty state.
- **Win95 authenticity**, legibility (the peak numbers were invisible in the dark theme) and the real
  bugs of the re-audit: unescaped aliases, an invalid channel list that became channel 1,
  "saved" announced when validation had rejected it, and an old macro armed with no address that
  fired a real mute.
- **Build script fix**: the DMG unmount retries and uses `-force` (with ten of our DMGs
  mounted, the normal unmount clashed and aborted the build without leaving artefacts).

Full re-audit report: `docs/UI_UX_REAUDIT_2026-09-21.md`.

## The Dock icon on macOS 26

macOS 26 (Tahoe) forces app icons into the *squircle* shape and composes a background behind the artwork. The
only thing it does not re-shape is a **custom icon**:

```
./scripts/set-custom-icon.sh "/Applications/WING CONTROLLER.app"     # after unlocking
./scripts/set-custom-icon.sh --check "/Applications/WING CONTROLLER.app"
```

Take the app out of the DMG, run the unlock **first** (its `xattr -cr` deletes the icon) and apply the
icon **after** signing. Measured: with it, 3.9% of the opaque pixels are dark (only the
marbling of the W); without it, 72.2% (the system's rounded square).

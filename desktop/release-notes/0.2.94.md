# WING CONTROLLER Desktop v0.2.94

Build: 20261008.1 (macOS Apple Silicon)
Date: 2026-10-08

## The cue list tells you where cues are added, and what a skip was

This release is the time-code cue system read end to end against its own words. Nine of the changes are things the
operator can see; the rest are the contracts that stop them coming back.

### The empty state and the state line

- **The card's empty state now names the window and the button.** It used to say *"Add cues in Settings"* — and
  Settings cannot add cues: its cue list is a read-only summary and the editor is the LTC window. The same window
  already carried the right sentence, so this is the stale copy catching up rather than new wording.
- **The card and the compact badge now show the freewheel tolerance and the re-arm sentence.** They phrased the state
  themselves, in lower case and without the one number the dropout-versus-seek work is about. The sentence has one
  home; both surfaces call it now, and the card gained two facts it had been missing.

### A skip says what was measured, and what was not

- **The log no longer asserts a seek.** It wrote *"skipped (the position was seeked past it)"* one line below the
  statement that already had the measured verdict in hand.
- **The last-run record carries how long a dropout lasted.** It could say *"the timecode had stopped arriving"* and
  never say for how long, while the row marks and the history line had always shown it.
- **A cue whose problem this build cannot word reports *unknown*, not *fine*.** It used to be drawn with its broken
  tag while the chain built to explain it reported every link healthy.

### Every frame rate, not only 25

- **The clock window interpolates and counts down at the right rate.** The engine's rate label was being handed to a
  lookup that expects this module's own key, and three of five call sites fell through to 25 — so the clock ran at the
  wrong frames per second for every rate except 25.
- **A cue at 23.976 is stored at 23.976.** The two parsers that turn a rate label into a rate had four arms where the
  engine publishes five, so 23.976 fell back — and LTC refused the rate outright.
- **A cue added from the macro editor takes the next free id.** It minted its own, in a shape the uniqueness scan does
  not recognise.

### The guide

- **It says three readings, not two.** A skip whose verdict was never measured reads *"the position moved"*, and the
  guide had been counting two since before that reading existed.

## What is measured

The full source gate is green: 70 checks, including the eleven browser suites that drive the real windows. Twenty-three
PLACEHOLDER and each is caught by the contract written for it. **Not measured**: the
packaged application's own WKWebView view — that needs this build and a person.

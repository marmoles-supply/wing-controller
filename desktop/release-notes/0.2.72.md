# WING CONTROLLER Desktop v0.2.72

Build: 20261004.2 (macOS Apple Silicon)
Date: 2026-10-04

This version exists because 0.2.71's audio fix was declared and **not delivered**, and the way that was found matters
more than the fix.

## The correction

0.2.71 said the audio input needed two things and that both were now declared: the `Info.plist` description macOS
shows, and the entitlement the hardened runtime checks. Both **were** declared in the repository — and **neither
script that builds the application used the entitlement**. `desktop/build-dist.sh` re-signs the whole bundle
ad-hoc, and that signing call did not pass `--entitlements`, so it threw away whatever the bundler had applied. The
installed 0.2.71 consequently reports **no entitlements at all**, which is why the audio input listed devices and
could not open one.

The fix is one line in the build — sign with `desktop/src-tauri/entitlements.plist` — and `verify-install.sh` now
**measures** the signature for `com.apple.security.device.audio-input` instead of trusting the declaration. The
signing was proved on a copy of the previous build before this one was made: the entitlement is present and the
strict signature verifies.

## What else this version carries

Everything 0.2.71 carried, which the owner tested and reported: *Add an application* works (it was being refused by
the backend's own rule about names), the clock opens as a popup from the toolbar beside **Meters** and from the
Timecode card, the tabs are **MIDI, Inter-app OSC** and **Timecode (MTC, LTC, SMPTE)**, the right-hand column shows a
**Timecode** card and a **MIDI, Inter-app OSC** card, the macro editor lists the bindings that fire the macro on
screen and can make one, and both pages carry step-by-step instructions while the guide gains chapters 12 and 13.

## What has still not been proved

The audio input against a real signal: this machine's only input is its built-in microphone, so LTC needs an
interface or a virtual audio device (BlackHole, Loopback) at the desk. The Mixing Station acceptance pass is still
unrun. And the lesson this version was born from is worth stating plainly: a green gate proves the contracts that
were written, not that the feature works.

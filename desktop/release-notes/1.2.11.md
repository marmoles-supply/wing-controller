# WING CONTROLLER Desktop v1.2.11

Build: 20260920.5 (macOS Apple Silicon)
Date: 2026-09-20

## Macro library controls

- Delete now uses a visible in-app confirmation and removes the checked macros. An empty library stays empty after save and relaunch.
- Right-click a macro row for open, enable/disable, courtesy notice, duplicate, rename in editor, move up/down, copy JSON and delete. These use the same toolbar operations.
- Batch enable/notice no longer saves an unsaved draft over an existing macro. Dragging down reorders at the indicated position.

## Validation and boundary

- No WING protocol or live trigger logic changed. No macro action was sent to the console during this build.
- Native empty-library persistence and legacy import parser tests pass; UI and package checks recorded in session results.

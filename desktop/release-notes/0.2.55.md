# WING CONTROLLER Desktop v0.2.55

Build: 20260926.2 (macOS Apple Silicon)
Date: 2026-09-26

Supersedes 0.2.54 (built an hour earlier) and carries everything since: the console checks the last
plan left open, the whole catalogued walked live against the desk, and a pass over the window the
owner asked for — no silent send destination, warnings that can be silenced, Enter that accepts, and
one chevron everywhere.

## `ptap`, the solo switches, and what the desk settled

The console (a WING Rack, verified on hardware) answered the checks the previous batch left open, and three
of them changed the catalogue:

- **`/ch/N/ptap` is offered now.** It is a string enum: the eight documented values (`IN, FILT, 3, 4,
  5, PFL, AFL, POST`) are taken verbatim, an int write is ignored, and a value outside the list leaves
  the previous one in place. Channels only.
- **`Solo Dim`, `Solo Mono` and `Solo Flip` became targets** — a write latches on the desk — while the
  three source-solo reports (`$srcsolo`, `$srcsgrp`, `$srcsin`) do not latch and stay watches.
- **`comp_ratio` needed nothing**: `/ch/1/dyn/ratio` reports `"3.0"` and a float write lands, which is
  what the app already sent.

## A send without a destination has no address

The step and gate panels pre-selected Bus 1 (Matrix or Main 1) for every send, so the destination the
macro really wrote was invisible — and on a bus that default is the bus's own send, which footnote 38
says the console ignores. The destination field starts empty, the list opens with "choose the
destination", the value is refused with the range to fill in until one is chosen, and the resolver
builds no address at all without one. The Send preset picks the parameter, not the bus.

## Warnings you can silence, and Enter that accepts

A warning that offers it (Shoot, PANIC STOP, discarding an unsaved draft) carries **Do not show this
again for this action** and **Do not show any of these warnings again**. A muted warning proceeds
without asking, and Properties → General → Warnings lists every muted one with its own restore button
plus **Restore all warnings**. Only a warning that carries a key can be muted, so the irreversible
confirmations always ask.

`Enter` accepts the primary action of every dialog — Shoot, quit, save, Properties, the channel
matrix, station backup — while `Escape` still cancels, text fields keep Enter for themselves, and only
the front-most dialog answers.

## Red means something again

The red accept button was on eighteen dialogs, eleven of which were plain reports ("Could not save the
macro", "Meter watchlist not applied", "Could not stop the stream", "PANIC STOP FAILED", the backup
failures, the preflight refusal). Those acknowledge with the normal button now. Red stays where the
action destroys something or aborts live work: delete, discard, remove, replace, factory reset, PANIC
STOP, and Shoot — a real write to the console.

## One chevron, and panels that hold their grid

Every dropdown draws the same bare chevron now (the native lists had the old boxed Windows-95 arrow
while the grouped picker drew a plain one), in both themes. And a field that appears and disappears
with the selected parameter — the send destination, wait, fade, the trigger's edge — keeps its grid
cell instead of collapsing it, so the two columns stay in line with the rows above whatever
configuration is being built.

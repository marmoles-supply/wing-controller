# WING CONTROLLER Desktop v0.2.74

Build: 20261004.4 (macOS Apple Silicon)
Date: 2026-10-04

Everything the owner found by using 0.2.73, and the contracts that make each one stay fixed.

## The dead button that was pressed all along

Under the feature switch there was a **disabled** button — "Add application…", with a tooltip saying *adding an
application arrives with the MIDI support* — left over from an earlier phase, with no handler at all. That is the
control the owner pressed. Worse, the settings test **demanded** that it stay disabled and keep saying that: the gate
was defending the placeholder. Both are gone; the editable list with its working button sits where the placeholder
was, each row now says whether the application speaks **MIDI or OSC**, and the contract asserts the opposite of what
it used to.

## The clock window

- **It was light grey in a dark application.** It now reads the same `wing_theme` key the other windows write,
  applies the same `theme-dark` class and follows the same `storage` event, with the dark values taken from the
  application's own dark theme.
- **"Only a black line, no timer."** Its placeholders are back — dimmed, and sized to the window — so a clock with
  nothing to show looks like a clock waiting, instead of a black well or 92-pixel dashes that read as a failed
  display. The readout was also overflowing the 420 x 200 window it opens in, which had pushed the state, the next
  cue and the counters out of sight.

## What now proves it

Every defect above is **put back on purpose** by `scripts/mutation-check-interapp.mjs`, which demands that a test
fails and names it. All five are caught. Alongside it, `test-desktop-interapp-smoke-browser.mjs` presses **every**
control of every new surface and checks that the click reached the backend, that nothing threw, and that the layout
survived — and the gate runs it, which is why the count went from 49 to 50 checks.

## Still not proved

The audio input against a real signal: this machine's only input is its own microphone, so LTC needs an interface or
a virtual audio device at the desk. And the acceptance pass with Mixing Station.

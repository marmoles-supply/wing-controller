# WING CONTROLLER Desktop v1.2.14

Build: 20260921.1 (macOS Apple Silicon)
Date: 2026-09-21

## Macro system reliability

- Disabled IF rules now survive Save Draft and reopening instead of disappearing from the macro.
- Editor action/condition arrays are detached from saved library objects. Unsaved edits can no longer leak into a saved macro when toggling notice, enable, tags, or other library controls.
- Added an explicit Enable selected action control. Disabled timeline steps survive normalization and reopen as OFF.
- New creates a fresh backend-default macro, always disabled, instead of cloning the selected macro's trigger and timeline. New meter macros start at -18 dB.
- Loading a draft no longer mutates the saved macro's enabled state.

## Editor and validation coherence

- Meter triggers expose only supported crossing operators (`>` and `<`); OSC state triggers can use equality and inequality. Preflight now accepts equality for OSC state triggers.
- Preflight now accepts Alert/HUD actions and does not require an OSC address for them.
- IF and action rows have distinct context menus. IF field loading uses the current schema, and duplicate/delete keep selection coherent.
- Timeline context Test This Step now loads and executes the selected step; deleting the final action is blocked consistently.
- Removed hard-coded CH range shortcuts from generic channel context menus; use the category-aware Matrix.
- Added a native contract test proving every trigger/action parameter exposed by the catalog resolves to a real meter or OSC target.

## Validation boundary

- Passed the full browser macro workflow smoke, TypeScript, HTML script syntax, HA/X32 checks, Android MacroEngine policy simulation, UI regressions, and 81 native Rust tests.
- No live OSC action was sent during this audit. Real-WING trigger/action/reconnect validation remains required before show-use signoff.

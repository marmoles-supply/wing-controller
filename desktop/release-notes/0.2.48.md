# WING CONTROLLER Desktop v0.2.48

Build: 20260923.1 (macOS Apple Silicon)
Date: 2026-09-23

Saving is where you look for it (Export/Import of the macro list), the saves folder exists from startup and
on closing it warns you about the unsaved show.

## The Export/Import you were pressing

The **Export** and **Import** buttons next to the macro list wrote and read a fixed file
(`~/Desktop/wing_macro_library_export.json`) **without opening any dialog and without asking what to save**.
That is why "no dialog appeared and the macro list changed colour for a moment": that was the list
repainting after writing the file. The backup with dialogs was in Properties → Profiles & Backup, where you
were not looking.

Now those two buttons are **the same backup**:

- **Export…** first asks **what the file carries** (Macros and Meters already ticked, which is what a show
  needs) and **what it is called**, and then opens the system Save panel. If the panel cannot be used, the
  file lands in the saves folder and it tells you.
- **Import…** opens the file picker and then asks **which sections to apply**; when it comes back, the
  window **says what it has restored**.
- A loose library file from an earlier version **still loads**: it is offered as a macros-only backup.
- The buttons are now called **Export…** / **Import…** and the Inspector describes them.

## The saves folder, from startup

The app **creates `Documents/WING CONTROLLER backups` at startup** (not only when saving), so it is there
from the start and you see it in Finder. In the Backup panel the current folder appears, with the
**Folder…** button to change it, and where the last backup was saved from.

## On closing, it warns about the show (not only the macros)

The close warning only talked about **unsaved macro changes**. Now it also warns about the **unsaved show**:
there is no backup, or the library or the watchlist has changed since the last one. The text says both
things when it applies and the button becomes **Quit anyway**.

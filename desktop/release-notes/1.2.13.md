# WING CONTROLLER Desktop v1.2.13

Build: 20260920.7 (macOS Apple Silicon)
Date: 2026-09-20

## Macro name editing

- Moved Macro name to the top of the editor, outside the Trigger Signal section.
- Added a visible rename button on each saved macro row. It edits the name in place; Enter or leaving the field saves, Escape cancels.
- Renaming a library row changes only that macro's name, preserving its saved trigger, conditions and actions. The selected editor name stays in sync when it has not diverged as a draft.
- The existing right-click Rename in Editor action remains available.

## Validation and boundary

- Automated Chrome interaction tested pointer hit, focus, typing, inline rename, editor-field rename and preservation of the saved trigger channel in the standalone desktop UI.
- No WING protocol, meter decoding or live macro runtime behavior changed. No OSC actions were sent during this validation.

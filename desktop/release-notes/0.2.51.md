# WING CONTROLLER Desktop v0.2.51

Build: 20260924.1 (macOS Apple Silicon)
Date: 2026-09-24

A show is one file that is updated, the save/load dialogs fit their content, and the dock's meters
can be moved and removed.

## One file per show

The saved file used to be `wing_<slug>_<date>.wingstation.json`, so saving the same show on another
day left another file. Now it is **`<show name>.wcz`** — the app's own type for a saved show, so it is
recognisable in the Finder — and saving again **replaces that file**, which is what saving a show
means. The date is gone from the name. Older `.wingstation.json` and `.json` files still open.

## The save and load dialogs

Both inherited the base dialog's fixed 560 px height, so a four-row list sat in a half-empty panel.
They now fit what they carry (about 240 px), and a single preference reads "1 preference".

## The meter matrix opens with the view

It used to arrive with the add field prefilled with `1-3`, so USB 1, 2 and 3 always looked selected
whatever the watchlist had. The field starts empty and the matrix ticks **exactly the meters that view
already has**, so it is a picture of the current selection: tick more and **Add to Meters**, or use
**Replace & View** to keep exactly what is ticked.

## The dock's meters: move and remove

Every tag in the strip carries `‹` and `›` to move that meter one place left or right — the strip
order is the order of the watchlist, which is the order of the meters in the view — next to the
existing `×` that removes just that one.

## Renaming a meter no longer keeps the cell in edit mode

Pressing Enter or clicking away committed the alias but left the inline editor inside the cell, and
the renderers skip a label that still holds an input: the cell stayed editable and the alias only
appeared after reloading the show. The editor now commits, writes the alias and leaves the cell at
once.

## What to try

1. Save a show as "Sala Grande": the file must be `Sala Grande.wcz`. Change something and save again:
   the same file must be replaced (the confirmation says so), not a second one created.
2. Open **Matrix...** for meters: nothing ticked on an empty view, and exactly your meters ticked
   when the view has some.
3. In the meter strip, use `‹` `›` to reorder and `×` to remove one; rename a meter and press Enter:
   the cell must return to normal immediately.

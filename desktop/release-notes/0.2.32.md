# WING CONTROLLER Desktop v0.2.32

Build: 20260922.5 (macOS Apple Silicon)
Date: 2026-09-22

This release closes the visual finish of the meters: **a single shared instrument** for both windows and
the **tuned history graph**, with its adjustable refresh rate.

## Analogue VU meter, one only for both windows

Before, the Meter Bridge and the side column drew **each their own dial** and they did not look alike. Now
both use the same instrument (`desktop/ui/vu-draw.js`).

- **The scale is in dBFS**, not in "VU": the data arriving from the WING is dBFS, and labelling it as VU
  was misleading (0 VU is not 0 dBFS). The red zone starts at 0, which is where clipping happens.
- **Major and minor marks** with their number, needle **with counterweight and hard shadow**, pivot with
  screw, **peak mark** and the channel name with the unit. No glows or smooth gradients: the same rule as
  in the rest of the interface.
- **Real ballistics**: fast attack and slow return, per channel. The needle chases the signal and comes
  back with inertia, like a real VU.
- The pivot sits **inside** the canvas (before it was drawn outside and the needle seemed to come out of
  the edge).
- Light and dark theme, each with its own face and its labels.

## History graph ("Win95 Task History")

- **It scrolls continuously.** Before it was drawn with `x = index * (width / 59)`, so each sample
  appeared all at once a full step to the right and the response looked **jerky**. Now samples carry a
  timestamp and the trace moves inside a time window, with interpolation between one sample and the next:
  the same data, but smooth.
- **Grid with labels in dBFS** (0 to −60), thin trace **without the `shadowBlur`** (that glow was a modern
  effect, out of style), peak line and "now" mark on the right edge.
- The window keeps **more samples** (up to about 6 seconds of data) instead of a fixed 60, so the trace is
  richer.
- **Adjustable refresh rate** in *Settings → Audio Displays → Graph Refresh Rate*: 60, 30 (by default), 20
  or 10 fps. It changes **the smoothness of the canvas motion**, not how much data arrives from the
  console (that is set by the graph speed).

## The Dock icon on macOS 26

macOS 26 forces icons into the *squircle* shape and composes a background behind the artwork; the only
thing it does not re-shape is a **custom icon**:

```
./scripts/set-custom-icon.sh "/Applications/WING CONTROLLER.app"     # after unlocking
./scripts/set-custom-icon.sh --check "/Applications/WING CONTROLLER.app"
```

## Corrections from the 2026-09-22 audit

- **"The window keeps more samples … instead of a fixed 60" was not true in this release.** In the 0.2.32
  commit the formula is `Math.max(60, Math.round(currentGraphSpeed * 6))` with speed 1..10, so it still
  kept **60 samples** and only the time span changed. The real change (sampling at the refresh rate)
  arrives in 0.2.34.
- **"Thin trace without the `shadowBlur`" only describes the Meter Bridge.** The working window still
  draws with `ctx.shadowBlur = 4` and by index over a fixed buffer of 60 samples; the one that uses
  `WingVu.drawHistory` is the bridge's.
- The path of the preference is **Settings → Meters & Popups** ("Audio Displays & Meters" is the legend of
  the block, not the tab).

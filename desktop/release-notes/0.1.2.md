# WING CONTROLLER Desktop v0.1.2

Build: 20260919.2 (macOS Apple Silicon)
Date: 2026-09-19

## Changes

- WING identity/liveness probes use Maillot `WING?` on UDP 2222. The OSC diagnostic button no longer takes over the sole `/*S` event subscription.
- Live status requires a valid WING reply. Missing replies cancel pending macro actions; optional reconnection starts a fresh session and trigger baseline.
- Native meter frames have their own watchdog, so identity replies cannot mask a stalled meter trigger stream. Changing a live watchlist updates the native TCP request.
- The selected network timeout applies to the native runtime and both meter windows.
- OSC control sends share a bounded global 17 ms pacing slot (at most 60 queued slots per second).
- F12 now invokes Panic Stop even while an input has focus. Panic stops pending activity; it does not undo commands already accepted by the console.
- Station backups now include all `wing_` preferences and restore library, draft and settings from the new schema v2 format, with macros disarmed.
- Macro library and draft saves use temporary files and a `.bak` recovery copy.
- Desktop version synchronization no longer overwrites Android/Expo package versions.
- Corrected OSC port labels, connection wording, meter bridge health event, and misleading help text.
- Saved filter steps with the legacy `/flt/cf` address migrate to Maillot `/flt/lcf` or `/flt/hcf` when their saved parameter identifies HPF or LPF; ambiguous steps fail preflight.
- Connection status now uses distinct offline and connecting indicators in the workstation.
- Library edits made during a live session are marked as taking effect on reconnect; the active macro count stays tied to the connected session.
- Connection indicators now follow the backend's validated receive timeout rather than a second, conflicting UI timer.
- Connecting to a WING no longer requires an enabled macro or a meter watchlist; an empty session can be used to establish communication without dispatching actions.
- The connection panel labels the macro count as configured, rehearsing, or listening according to the actual session state.

## Validation

- Automated Rust, TypeScript, JavaScript syntax and project safety checks run for this release.
- Real WING discovery, triggers, OSC control and reconnect still require an on-console validation pass before show use.

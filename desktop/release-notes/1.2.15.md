# WING CONTROLLER Desktop v1.2.15

Build: 20260921.2 (macOS Apple Silicon)
Date: 2026-09-21

## Meter stream repair

- Corrected Maillot Channel 3 `0xA7` Source and `0xA8` Output device selection. Logical group numbers are encoded zero-based, so USB Source 7 is now sent as `0xA7 0x06` instead of accidentally selecting Card Source 8.
- Applied the correction to every Source and Output family, including Local, AES50 A/B/C, StageConnect, USB, Card, Module, Player/Recorder, AES/EBU, User Signals, Bus, Main and Matrix sources.
- Assigns a new report id whenever the meter collection changes and renews the current id, preventing stale packets from being decoded with a different collection layout.
- Keeps dock, popup and macro runtime meter requirements separate and merges them safely. Closing or changing one view no longer removes meters required by another view or by triggers.

## Validation

- All 22 `wing-core` tests and all 46 desktop runtime tests pass.
- JavaScript embedded in both desktop windows parses successfully; TypeScript, HA, X32 and reliability checks pass.
- Read-only hardware validation against a WING on the network received the real USB group, a mixed USB/channel request, and all 878 values across 16 Source and 11 Output groups in documented order.
- No macro action or OSC control value was sent during hardware validation.

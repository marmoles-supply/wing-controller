# WING CONTROLLER Desktop v0.2.73

Build: 20261004.3 (macOS Apple Silicon)
Date: 2026-10-04

Two defects the owner found by pressing two buttons, both mine, both fixed with the test that should have caught
them.

## Settings… on the new cards did nothing

The two cards in the right-hand column have a **Settings…** button, and pressing it did nothing at all. The handler
called a function that exists in the window but **not in the scope that handler runs in**, behind a `typeof` guard —
so the failure was silent. That guard is the bug: a button that does nothing and says nothing is worse than one that
complains.

It now calls the global the application's own toolbar button uses (`window.openSettingsModal`), with a fallback that
clicks that toolbar button, and it **says so in the window** if neither works. The settings contract now **clicks
both buttons** and asserts that the dialog opens on the right page; it did not before, which is why a dead button
passed a green gate.

## The clock window looked broken

Opening the clock showed a black panel of **giant green dashes** and nothing else. Two causes, both visible in the
owner's screenshot:

- with no timecode the readout drew `--:--:--:--` at up to 92 px, and hyphens at that size read as a failed display.
  With nothing arriving the readout is now **empty** and the line underneath says **"Nothing has arrived yet."**;
- the position was sized for a much larger window, so in the 420 x 200 window it opens in it **overflowed** and pushed
  the state, the next cue and the counters **out of sight** — which is why only the dashes were visible. The position
  is sized to the window (and grows with it when the operator enlarges it), and the layout holds everything inside.

Measured, not assumed: at 420 x 200 the readout no longer overflows horizontally, the next cue ends at y=179 and the
counters at y=194 inside a 200-pixel window, with a position and with none. The clock contract now measures those
four things, so a future change that pushes a row out of the window fails the gate instead of reaching the desk.

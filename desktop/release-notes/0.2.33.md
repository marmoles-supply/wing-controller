# WING CONTROLLER Desktop v0.2.33

Build: 20260922.6 (macOS Apple Silicon)
Date: 2026-09-22

Release that closes the visual finish. On top of 0.2.32 it adds one thing:

## The step and IF gate rows carry their ramp

The gradient was missing in the list of *steps* and in the list of *gates*. The cause was that **the two
share the same class** (conditions are painted as `step-row condition-row`), so they had the same flat
blue when selected. A single entry in the dither module now covers both lists, with its dark theme
variant.

The module test checks that a selected step row is painted with the ramp; if the loaded macro has no
steps, that check is skipped.

## What already came from 0.2.32

- **A single analogue VU meter for both windows** (`desktop/ui/vu-draw.js`). The scale is **in dBFS**, not
  in "VU" (the WING data is dBFS; labelling it as VU was misleading), with the red zone from 0, major and
  minor marks, a needle with counterweight and hard shadow, a visible pivot with screw, a peak mark and
  **per-channel ballistics** (fast attack, slow return).
- **Tuned history graph**: samples carry a timestamp and the trace **scrolls continuously** (before, each
  sample appeared all at once a step to the right), grid with labels in dBFS, thin trace without
  `shadowBlur`, peak line, "now" mark and up to ~6 s of data.
- **Graph Refresh Rate** adjustable in *Settings → Audio Displays* (60/30/20/10 fps).

## What already came from 0.2.31

Ordered dither patterns on all the surfaces (title bars, panels, headers, selected rows), **pre-painting
at startup** so there is no flicker when each window opens, desktop background with a **diagonal ramp**,
seam in the background colour, 1 px margin in the blue bars and the dithered decoration of *Settings →
About*.

## The Dock icon on macOS 26

macOS 26 forces icons into the *squircle* shape and composes a background behind the artwork; the only
thing it does not re-shape is a **custom icon**:

```
./scripts/set-custom-icon.sh "/Applications/WING CONTROLLER.app"     # after unlocking
./scripts/set-custom-icon.sh --check "/Applications/WING CONTROLLER.app"
```

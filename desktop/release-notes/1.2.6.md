# WING CONTROLLER Desktop v1.2.6

Build: 20260919.8 (macOS Apple Silicon)
Date: 2026-09-19

## Key Highlights

- **Manual Test Shoot with Courtesy Notice Integration:**
  - Added dedicated `[✓] 🔔 Include Notice` checkbox directly beside the `[▶ Test Action (Shoot)]` button in Block 4 (Action Value).
  - Enabling this option displays the floating Win95 courtesy notice card immediately when performing manual preflight shoots, allowing sound engineers to preview the notification appearance and telemetry before arming macros.
  - Automatically captures and displays multi-step action tallies, target OSC address, parameter values, and destination IP.

- **Centralized Courtesy Notice Preferences (Properties Dialog):**
  - Added a dedicated configuration section under **Properties... (Cmd+,) -> HUD & Courtesy Notices**:
    - **Auto-dismiss duration selector**: Customizable duration (`2.0s`, `3.5s (Standard)`, `5.0s`, `8.0s`, or `Keep open until dismissed`).
    - **Screen corner placement**: Choice of 4 screen corners (`Bottom-Right`, `Bottom-Left`, `Top-Right`, `Top-Left`).
    - **Acoustic feedback**: Optional subtle sine-wave chime on macro trigger via WebAudio API.
    - **Defaults for new macros**: Option to automatically enable courtesy notice for newly created macros.
    - **[⚡ Test Courtesy Notice]**: Interactive button in settings to preview notice positioning and sound immediately.

- **Dialog Usability Polish:**
  - Enhanced `.win95-tabpage` scrolling with `min-height: 0` and generous bottom padding (`24px`), ensuring property sheet controls are never clipped or obscured by dialog footers.
  - Adjusted `#settings-modal` dimensions for comfortable viewing across all property sheets.

# WING CONTROLLER Desktop v0.2.50

Build: 20260923.3 (macOS Apple Silicon)
Date: 2026-09-23

The macro summary can now be read as cards, chosen in Settings.

## Two ways to read a macro

The WHEN / IF / THEN box above the editor was three lines of wrapped text. **Settings → General & UI → Appearance & Visual Theme → Macro
summary** now offers a second drawing: **one card per part**.

- **When** — what is watched (`Channels 36 · Meter Level`), what for (`rises above -20 dB`) and, as
  chips, the qualifiers that change how it fires (`ON edge`, `transient`, `cooldown 0 ms`).
- **If** — one row per gate with its number, and the AND/OR that joins them written between the rows.
- **Then** — the steps as a numbered list, with the disabled ones marked `OFF`.

Both presentations are painted from the same configuration as the sentences, so they cannot drift
apart, and neither changes what runs. The choice is remembered, it travels in a backup's settings
scope, and the default stays the classic three lines.

## Also in this build

- The guide's chapter on macros documents both presentations, and its library section no longer
  describes the old fixed desktop export path — that was replaced by the show's Save… / Load… in
  0.2.49.

## What to try

1. **Settings → General & UI → Appearance & Visual Theme → Macro summary**: choose **Cards** and
   close the window. The
   WHEN / IF / THEN box must now be three cards.
2. Open a macro with two IF gates and three steps (one of them switched off): the gates must appear
   one per row with `AND` between them, and the steps numbered with `OFF` on the disabled one.
3. Switch back to **Lines**: the classic readout must return, and the choice must still be there after
   closing and reopening the app.

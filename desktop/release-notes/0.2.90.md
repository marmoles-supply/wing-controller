# WING CONTROLLER Desktop v0.2.90

Build: 20261005.12 (macOS Apple Silicon)
Date: 2026-10-05

## The courtesy notice governs every path that fires a macro by itself

0.2.89 made a macro fired by a cue show its courtesy notice, and left one path out: a macro fired by another application
over MIDI or OSC still showed nothing while its own NOTICE button read on. A toggle that governs three of the four ways a
macro can fire is not a toggle, so this release closes it.

The notice now appears for a macro fired from another application when that macro's toggle is on, and names the transport
it came in on - "MIDI from another application" or "OSC from another application". It names no application and no console:
the transport and the fact that it came from outside are what the operator needs. The context menu's Fire Macro stays
silent, because there the operator has just pressed the button himself and a card telling him what he did is noise.

The setting itself is still read in exactly one place, so all four paths cannot drift apart again.

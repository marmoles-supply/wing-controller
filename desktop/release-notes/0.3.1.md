## Meter trigger cooldown

- The cooldown starts when a meter-triggered macro takes its execution slot.
  For a queued run, that is when the scheduler starts the run.
- One cooldown covers all meter inputs in the same macro. A hit blocked by an IF
  leaves the timer available for the next eligible hit.
- Hits during cooldown are discarded. Session Log records the first skipped
  trigger in each interval.
- The guide, Inspector and hover help explain Transient, Level edge, rearm,
  dwell and cooldown. Diagnostics counts meter detections separately from
  macro starts.

## Soundcheck

Saved macros retain their configured modes and cooldown values. Use the
actual playback set and console to check the interval between intended cues.
Confirm one start per cue and check the resulting console state. Native toggles
are reported as sent. The console state is the check for their outcome.

The desktop regression tests exercise synthetic USB meter reports and the
cooldown scheduler. This release's show-specific hardware check is pending.

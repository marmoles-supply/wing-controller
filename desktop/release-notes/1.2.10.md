# WING CONTROLLER Desktop v1.2.10

Build: 20260920.4 (macOS Apple Silicon)
Date: 2026-09-20

## Network route preference

- Settings > Console & Network now lists the Mac's active IPv4 adapters by interface name and address. Automatic probe remains the default.
- A selected adapter is tried first. With "Use only the selected adapter" enabled, discovery and Live fail clearly if that adapter is unavailable or the WING does not answer through it; no silent Wi-Fi fallback occurs.
- The preference applies to targeted/broadcast Maillot `WING?` discovery on UDP 2222, native meter TCP/UDP, OSC subscription and manual control sends. The selected source is frozen for a Live session and re-evaluated on reconnect.
- The actual chosen route is shown in Network Settings during Live and recorded in the log. The preference is included in station backups and factory reset.

## Validation and boundary

- The identity probe and broadcast discovery were verified on hardware through the selected Ethernet adapter while Wi-Fi remained enabled. No OSC control or saved macro was executed.
- Rust workspace, TypeScript, HTML JavaScript syntax, safety, reliability, HA and X32 checks passed.
- Full app-level trigger/action latency and link-loss reconnect still need a controlled hardware test before show use.

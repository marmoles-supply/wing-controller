# WING CONTROLLER Desktop v0.2.37

Build: 20260922.10 (macOS Apple Silicon)
Date: 2026-09-22

Two reported faults, both fixed and verified.

## The meter style is no longer linked between windows

The style (bars / VU / graph) was **shared on purpose**: the working window also wrote the Meter Bridge key
and the bridge listened to the working window's. Result: changing the style in one window changed the
other, which is exactly the opposite of what you want when the popup is on a stage screen and the side
column is on the desktop.

Now **each window is in charge of its own**: the working window writes `wing_meter_style` and the bridge
`wing_meters_style`. The bridge inherits the working window's value **once only** if it does not have its
own key yet (with the translation of the old value), so nobody's style changes on update.

Verified: with the bridge on `vu` and the working window on `bars`, each key keeps its value.

## The custom bank selector now really filters

Choosing a bank in the side column **changed nothing**. It was two chained problems:

1. The handler updated the active bank id and the labels, but **did not repaint** the list of meters.
2. And, more fundamentally, the render built the meters from the full watchlist (`customMetersWatchlist`)
   instead of `visibleMeters()`, which is the function that applies the bank filter.

With both things fixed, choosing a bank filters the list. Checked with data: three meters in the watchlist
and a bank with only one of them leaves **1 meter visible**.

## Also in this release

- **The bridge scale slider test now pins down its style precondition.** It failed if another test left the
  window in VU (the slider only exists in the bars style), and that happened while verifying these
  changes.
- New contracts in the Settings test: the working window cannot write the bridge style key again, and the
  meter render must use `visibleMeters()`.

## What already came from 0.2.36

The desktop background in the dark theme (its preset was not chosen), the grey gradient in the block

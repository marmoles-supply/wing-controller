# WING CONTROLLER Desktop v0.2.36

Build: 20260922.9 (macOS Apple Silicon)
Date: 2026-09-22

It closes the loose ends of the finish: the popup zoom, the header hierarchy, the background in the dark
theme and the interface names. **It replaces 0.2.35**, which carried the dark background bug.

## The desktop background now does change in the dark theme

`presetFor()` had no case for the desktop, so it **always returned the light preset**: the dark ramp
existed in the code but was never chosen, and in Dark the background was still the light teal. Reproduced
by measuring the whole pattern (light `34341:1723992811` against dark `34609:-1082477574`) and pinned down
with a behaviour test that switches theme and back, checking that the pattern becomes exactly the same
again.

## Header hierarchy

- **The grey gradient leaves the panel bodies and moves to the block headers**, which is where it gains
  importance: `Build Macro`, `1. Trigger Signal` and the other groups. The bodies stay **flat**.
- **`Build Macro` stands out** from the rest: it uses its own ramp, darker and with a longer range, so it
  reads as the header of the block and not as a group subheader.
- **1 px outline on the headers of the right column** (`Inspector`, `Connection`, `Meters`…): without it,
  the transition between the ramp and the block background looked dirty.

## The Meter Bridge zoom no longer moves the side column's

Both windows wrote the same key (`wing_meter_scale`) and in the real app they share storage, so moving the
zoom in the popup also changed the desktop meters'. The bridge now has its own key
(`wing_bridge_meter_scale`), inheriting the value once only so nobody's size changes on update.

## The interface does not name the aesthetics

The looks are called **"Light (Classic Slate)"** and **"Dark (FOH Low Glare)"**, the meter style is
**"Task History Graph"**, and descriptions, tooltips and labels are rewritten in neutral terms. A contract
in the Settings test fails if "Win95" or "Windows 95" appear again in either of the two windows.

## What already came from 0.2.34

The graph samples at the refresh rate (5..120 per second; measured: 120/s → 106 samples in one second) and
scroll decides how many seconds of history fit on screen; and the custom icon is no longer a manual step
(the build applies it and checks it, the unlock restores it and the helper travels inside the package).

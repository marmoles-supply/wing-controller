# WING CONTROLLER Desktop v0.3.2

Build: 20261118.1 (macOS Apple Silicon)
Date: 2026-11-18

## Meter-triggered macros

- Includes the cooldown changes from 0.3.1: the interval begins when a macro
  takes its execution slot, is shared across that macro's meter inputs, and is
  not consumed by a hit refused by its IF conditions.
- Adds configurable IF timing for meter triggers. Immediate keeps the existing
  behaviour. Wait for next report lets related meter reports reach the engine before
  it evaluates the IF conditions; macros using the same settings share the same
  detector and decision window.
- A deferred hit with no fresh IF report is discarded after 125 ms and reported
  in Session Log. Pending decisions are cleared when subscriptions change.
- The Inspector, hover help and guide explain the available timing choices.

## Tests and publication

- The GitHub source now includes the meter cooldown and IF timing changes, with
  synthetic engine tests and browser checks for the editor settings.
- Build tools handle filesystem paths containing spaces and remap both logical
  and physical checkout paths. The binary audit also checks named macOS volumes.

This is an independent, self-signed Apple Silicon community beta, not notarised
by Apple. Source and package checks are recorded separately from physical
console/show acceptance. LTC still needs independent signal/interface testing.
Rehearse saved macros with the actual playback and console before live use.

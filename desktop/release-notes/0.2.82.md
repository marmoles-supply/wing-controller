# WING CONTROLLER Desktop v0.2.82

Build: 20261005.4 (macOS Apple Silicon)
Date: 2026-10-05

## Rates have one parser, and no button may stay silent

Two defects from this week's work, both of the same shape - something an operator pressed answered nothing.

**The LTC file panel would not open on 29.97.** The rate selector offers 24, 25, 29.97 and 30, and the file verification
had a second, narrower list of its own that refused 29.97 **before** the panel could be shown. The two now share one
parser, so the selector and the reader cannot disagree again about which rates this build reads.

**The audio buttons could go silent.** Refresh and Ask macOS for microphone access touched CoreAudio through a promise
that could neither resolve nor reject, so neither the code after it nor its error path ran - the line stayed empty and the
section looked dead while the rest of the window worked. Both waits are now bounded and both say what they are doing
before they wait, with a message that names the setting to check when the system does not answer.

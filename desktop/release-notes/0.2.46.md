# WING CONTROLLER Desktop v0.2.46

Build: 20260922.19 (macOS Apple Silicon)
Date: 2026-09-22

The backend asks for the save/open backup panel —and if it fails, you see it—, plus the report's interface
finishing touches.

## The backup dialog, fail-safe

In 0.2.45 we premiered the system Save/Open panel, but the window asked the plugin for it **over IPC**. If
that call failed —a permission, a command name, an argument— the code fell silently to a browser download
that in the packaged app **writes nothing**: the operator was left without a backup and without any
message. It was the symptom "it is not there or it does not work".

- The panel is now requested by **Rust** with the plugin API (`save_station_backup` /
  `open_station_backup`): no IPC, no ACL and no guessing names or arguments, and **anchored to the
  window**, so on macOS it comes up in front and not loose behind.
- **A failure is visible**: a dialog with the reason and `station_backup_export_failed` in the log. Silent
  degradation is over.
- The dialog permissions that are no longer needed come out of the capabilities.
- The test covers all of it: it requests the panel, writes where the system says, cancelling writes nothing
  (and stays as `station_backup_export_cancelled`), a failure shows the reason, the **show name** names the
  file and the **folder is remembered** for the next one.

## Interface

- **RENAME and NOTICE are no longer huge.** They measured the same as ENABLED/OFF and carried the same
  thick bevel, which made every row of the library heavy. Now they are 40×15, flat (thin border and text,
  no inner bevel), and **ENABLED/OFF** is still the big control (54×18).
- **Light theme of the meter, without black holes**: the **CLIP** LED when off was an almost black square
  on the grey card and the bar's recess was pure black. Now the CLIP when off is a grey button with
  crimson ink (red when it trips) and the recess is dark grey, which still gives contrast to the LEDs.
- **The PK box no longer moves the dB scale**: going from `PK --` to `PK -56.4` made it grow, the scale
  shrank and the graduations shifted. It has a fixed width (58 px).

## Verification

`./scripts/verify-all.sh`: **39 checks** — TypeScript, syntax of the three windows, 35 Node tests (18 of
them driving the real UI in Chrome), the strict Maillot path audit and `cargo test --workspace`.

Honest note: the native panel is provided by macOS. The gate drives all the wiring in Chrome and a backend
failure is covered by test; the panel itself is seen when using it.

## What to try

1. **Backup per show**: Properties → Backup, type a show name, tick **Macros** and **Meters**, **Export
   station backup**: the Save panel must open (in front of the window) with
   `wing_<show>_<date>.wingstation.json`; on saving, a notice says **where it went** and what sections it
   carries. Repeat and check that it remembers name and folder. Cancel the panel: nothing is written and
   the log says `station_backup_export_cancelled`.
2. **Load a show**: **Restore station backup**, choose the file and leave only **Macros** ticked (or only
   **Meters**): only that changes, and the network and the settings stay as they are.
3. **Macro row**: look at RENAME and NOTICE next to ENABLED/OFF: the first two must read as secondary
   actions, smaller and flat.
4. **Meters in light theme**: the CLIP when off must not be a black square, the bar's recess must not be
   pure black, and when signal arrives the dB scale **must not move** as the PK number appears.

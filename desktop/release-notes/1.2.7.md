# WING CONTROLLER Desktop v1.2.7

Build: 20260920.1 (macOS Apple Silicon)
Date: 2026-09-20

## Key Highlights

- **Fix for "The application 'WING CONTROLLER' can't be opened" on Apple Silicon (M1-M5, macOS Sequoia / Sonoma):**
  - **Sanitized `Info.plist`**: Stripped legacy 1990s Carbon attributes (`LSRequiresCarbon`, `CSResourcesFileMapped`) that caused LaunchServices to reject the app on modern Apple Silicon Macs. Set `LSMinimumSystemVersion` explicitly to `11.0` for arm64.
  - **Mach-O Ad-hoc Code Signing & Resource Sealing**: Automatically codesigns the entire `.app` bundle (`codesign --force --deep --sign -`), sealing all resources and frameworks so the macOS kernel accepts execution.
  - **Modern GPT / HFS+ Disk Image (DMG)**: Replaced legacy `makehybrid -hfs` with native GUID Partition Table (GPT) HFS+ disk image creation, fully compatible with macOS Sequoia Gatekeeper.
  - **One-Click Gatekeeper Helper**: Included `Desbloquear WING CONTROLLER.command` inside the DMG installer to easily remove quarantine (`xattr -cr`) if blocked by Gatekeeper.

- **Maintains All v1.2.6 & v1.2.5 Features**:
  - Courtesy trigger notice toasts with live shoot testing.
  - Quick Templates in header and flat un-beveled accessory drawers.
  - Saved Macros drag-and-drop reordering, multi-selection, color tags, and live search.

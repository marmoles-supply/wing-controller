# Security reporting

Do not post credentials, private console details, customer data or exploitable
vulnerability details in a public issue.

Use GitHub's **Security → Report a vulnerability** for this repository:
[private vulnerability report](https://github.com/marmoles-supply/wing-controller/security/advisories/new).
Private reporting was enabled on 9 November 2026. Do not substitute a public issue
for a confidential report. No response-time, maintenance or supported-version
commitment is made for this community source preview.

Include the affected version, platform, impact and a minimal reproduction with
synthetic data. If a real credential was exposed, revoke or rotate it: deleting
the current file does not revoke a credential or remove historical copies.

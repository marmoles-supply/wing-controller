How to read this page — the composed plan, and which sheet draws what

The skeleton is <main> → <header class="master-header"> → .layout → .stack of cards, and it is the same skeleton every window of WING CONTROLLER is built on.

layout.css owns the plan: main's width on the desktop, the master header's row, the two-column .layout and its 6px seam, the .stack gap, the sticky operator column, and the folded card. components.css owns everything you can see inside those regions — the card, the row, the well, the chip, the band, the field — and tokens.css owns every colour and size either of them uses. This page carries no fourth opinion: it links the three sheets and adds only the labels.

Which card goes where. The left column is the window's subject — its list, its editor, its detail — and it is the flexible one: it grows with the window and its cards never fold. The right column is the window's standing instruments — what the operator checks rather than edits — and it is the fixed one: sticky under the header, scrolling inside itself, and it is its cards that fold.

How the height is shared. It is not. The plan shares a row, not a height (align-items: start), so each column is as tall as its own content; the operator column stays useful by being sticky rather than by stretching. And the plan is not one width: below 1400px the operator column is limited to what is free, and below 1180px the plan becomes one column, the seam is hidden and the header stacks — both bands are in layout.css with the overflow that was measured when they were missing.

What this page deliberately is not. It is structure, and its labels are almost all of its content: the chips label regions and do not act, and no greyed placeholder is drawn, because a mockup that shipped one would be exactly the promise this project forbids. The page carries **one** control and one handler — the folded card's toggle — and it is here because `PLAN.md` records the gap a stranger found: the fold was a state with no way to change it. It is the same mechanism as the reference window's, so a consumer copies one thing.

WING CONTROLLER — design kit specimen

Every value the kit declares, and every component it names, in both themes

This is the reference an agent opens when it has to make something look like the kit and cannot see a screen. The two columns are the same markup under the two themes: light is :root, dark is body.theme-dark, and they are shown together so a difference between them is visible rather than remembered.

How to read a sample. Every sample is a card labelled with the token's CSS name. Beside that name the card prints the value that card resolves to in this column, read from the live cascade when the page loaded — so a printed value cannot disagree with the colour or size next to it. A reading that is measured rather than declared (a border colour, a font size) is printed after the arrow. Type a token name into the filter to find its sample; each name appears once per column.

Nothing here is downloaded: the only files this page links are tokens.css and components.css, both in this folder — the kit's values, then the kit's drawings of them, which is the order a consumer links them in too. The kit itself carries no JavaScript on purpose; this page carries one small local script, because it has to read the live values and show two themes at once — a script in this folder is still nothing downloaded and no build step. The kit's version is the one in VERSION — this page does not copy the number, so it cannot go stale. The dark column is drawn by re-declaring, on that column only, the values the dark cascade resolved; everything the dark theme inherits keeps inheriting, which is how the type scale stays one knob for both columns.

meter — a bar showing a level the instrument reports. --meter-ramp is the track’s own background, laid out once across the whole track, and .c-meter-mask is the unlit cover anchored to the right; the reading is a percentage written where the meter is used (style="--meter-level: 74%"), and the cover’s width is its inverse. Putting the ramp on the lit element instead squeezes green-to-red into the lit fraction — a quiet channel showing red at its end, which the conformance suite does not catch

field — a sunken area the operator types into; a value read as a number is --mono. The select is the same field plus the kit’s own arrow, drawn in --ink so it follows the theme: the platform’s arrow sits inside the control and does not respect the kit’s edge pair, and --line-dark would be invisible on the dark field (measured 1.04:1)

band — a full-width strip that carries one message, and names its cause in the operator's words. The three answers a machine can give are told apart by shape as well as by colour (§11.6): the confirmed and refusal bands are solid, the unknown band is dashed, and the unknown dot in the chip above is hollow — so a reader who sees no green, red or grey still tells a refusal from an absence
